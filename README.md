## 🕷️ نبذة عن الأداة

**SPIDER** أداة تواصل شاملة مصممة للتقنيين، تعمل على **Kali Linux** وجميع أنظمة التشغيل. توفر تجربة دردشة كاملة من الطرفية (Terminal) مع:

- 🔐 تسجيل ودخول آمن بكلمات مرور مشفرة
- 💬 محادثات ثنائية (Direct Messages)
- 👥 جروبات (خاصة وعامة)
- 🔍 بحث شامل في المستخدمين والرسائل
- 📎 إرسال نصوص، صور، ملفات، وروابط
- 🌐 **بدون أي حفظ محلي** — كل البيانات في قاعدة البيانات المشفرة
- ⚡ **يكتشف IP تلقائياً** ويشغّل الخادم بنفسه — أمر واحد فقط

## ❓ الأسئلة الشائعة

<details>
<summary><b>هل تعمل الأداة بدون إنترنت؟</b></summary>
نعم، تعمل محلياً على <code>localhost</code>. الإنترنت مطلوب فقط لاكتشاف IP العام وللاتصال بسيرفر بعيد.
</details>

<details>
<summary><b>هل تُحفظ البيانات محلياً؟</b></summary>
تُحفظ في ملف <code>spider.db</code> مشفر بـ Fernet. المفتاح في <code>spider.key</code> بصلاحيات 600.
</details>

<details>
<summary><b>ماذا لو نسيت كلمة المرور؟</b></summary>
لا يمكن استرجاعها (لأنها مشفرة). تواصل مع مسؤول السيرفر.
</details>

<details>
<summary><b>كيف يشارك أصدقائي؟</b></summary>
على نفس الشبكة: استخدم الـ IP المحلي الظاهر عند التشغيل. على الإنترنت: استخدم <code>ngrok http 8000</code> أو port forwarding.
</details>

<details>
<summary><b>ما هي أنظمة التشغيل المدعومة؟</b></summary>
Kali, Ubuntu, Debian, Arch, macOS, Windows (مع Python 3.8+).
</details>

<details>
<summary><b>هل يحتاج تثبيت قاعدة بيانات منفصلة؟</b></summary>
لا. SQLite مدمجة في Python، تنشئ قاعدة البيانات تلقائياً عند أول تشغيل.
</details>

## 🕷️ About

**SPIDER** is an all-in-one communication tool designed for tech professionals, running on **Kali Linux** and all operating systems. It provides a complete terminal-based chat experience with:

- 🔐 Secure registration and login
- 💬 Direct messages (DMs)
- 👥 Groups (private & public)
- 🔍 Comprehensive search (users + messages)
- 📎 Send text, images, files, and links
- 🌐 **Zero local storage** — all data in the encrypted database
- ⚡ **Auto-detects IP** and starts the server — one command does it all

## ❓ FAQ

<details>
<summary><b>Does the tool work offline?</b></summary>
Yes, locally on <code>localhost</code>. Internet is only needed for public IP detection and remote server connections.
</details>

<details>
<summary><b>Is data stored locally?</b></summary>
Stored in <code>spider.db</code> encrypted with Fernet. The key is in <code>spider.key</code> with 600 permissions.
</details>

<details>
<summary><b>What if I forget my password?</b></summary>
It cannot be recovered (it's hashed). Contact the server administrator.
</details>

<details>
<summary><b>How do my friends connect?</b></summary>
On the same network: use the local IP shown at startup. On the internet: use <code>ngrok http 8000</code> or port forwarding.
</details>

<details>
<summary><b>Which OSes are supported?</b></summary>
Kali, Ubuntu, Debian, Arch, macOS, Windows (with Python 3.8+).
</details>

<details>
<summary><b>Do I need a separate database?</b></summary>
No. SQLite is built into Python and the database is auto-created on first run.
</details>
